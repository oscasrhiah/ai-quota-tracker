# AI 額度追蹤器

Windows 桌面小工具：即時查看各家 AI 訂閱方案的用量與重置倒數。
關閉視窗會縮小到右下角系統托盤繼續倒數，雙擊托盤圖示可還原。

## 功能

- 同時追蹤多個服務：ChatGPT（GPT）、Codex、Claude、Gemini（Codex 與 GPT 額度分開計算）
- 每秒更新的重置倒數 + 剩餘次數進度條
- 週期到了自動歸零並發送 Windows 通知
- 關閉視窗 → 縮到系統托盤；托盤右鍵選單顯示下次重置時間
- 可新增 / 編輯 / 刪除服務（上限、週期、開始時間都能調）
- 開機自動啟動（選配）
- 資料存在本機（`%APPDATA%\AI 額度追蹤器\quota-store.json`），不需登入任何帳號

## 重要說明

OpenAI / Anthropic / Google 都**沒有提供訂閱額度查詢 API**，
所以用量需要手動按「用掉 1 次」（或在編輯裡直接填已用次數），
工具負責幫你算倒數、自動重置、縮托盤提醒。
內建的上限數字是常見公開值，請依你的實際方案修改。

## 開發

```cmd
npm install
npm run dev      # 開發模式（含熱重載）
npm run build    # 只是編譯檢查
npm run dist     # 產生 Windows 安裝檔（dist\*.exe）
```

## 使用

1. 執行 `npm run dist` 後，到 `dist` 資料夾執行安裝檔
2. 桌面 / 開始功能表開啟「AI 額度追蹤器」
3. 每次用了一次 AI，就回來按「用掉 1 次」（或一次填已用次數）
4. 不用時直接關閉視窗，它會留在托盤繼續倒數
